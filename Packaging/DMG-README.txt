Mode Runner
Created by ilia domyshev

1. Drag Mode Runner into Applications.
2. Open Mode Runner from Applications.
3. Look for its terminal icon in the macOS menu bar.

Mode Runner requires macOS 14 or later. It manages commands on your own Mac.
Xcode is not required to use the downloaded app.

The optional starter websites require Node.js 22.12 or later, with no npm
package installation. Your own projects need their usual tools and dependencies.

Documentation and support:
https://github.com/domyshev-labs/mode-runner
